# MES 设备管理与生产订单管理实现计划

> **给执行型 agent 的要求：** 必须使用 `subagent-driven-development`（推荐）或 `executing-plans` 按任务逐项执行。所有步骤使用 `- [ ]` 复选框跟踪。

**目标：** 补齐 MES 的设备管理页面、生产订单管理页面，以及后端生产订单展示型返回结构与状态校验，使用户可以维护设备主数据，并完成基础版生产订单的创建、编辑、删除和状态流转。

**架构：** 后端继续沿用 Spring Boot + MyBatis-Plus 分层结构，在现有 `device` 与 `order` 基础上新增展示型 `ProductionOrderVO` 返回对象并补强主数据校验；前端沿用当前产品管理、物料管理、工序管理的列表 + 弹窗模式实现设备管理和生产订单管理，并通过产品、工艺路线下拉完成前后联调。

**技术栈：** React 19、TypeScript、Ant Design、React Router、Axios、Spring Boot 3、MyBatis-Plus、H2/MySQL 初始化 SQL。

---

### 任务 1：补强后端生产订单展示返回与业务校验

**文件：**
- 新增：`backend/src/main/java/com/example/admin/dto/ProductionOrderVO.java`
- 修改：`backend/src/main/java/com/example/admin/mapper/OrderMapper.java`
- 修改：`backend/src/main/java/com/example/admin/service/OrderService.java`
- 修改：`backend/src/main/java/com/example/admin/service/impl/OrderServiceImpl.java`
- 修改：`backend/src/main/java/com/example/admin/controller/OrderController.java`

- [ ] **步骤 1：新增展示型订单返回对象**

新增 `ProductionOrderVO`，字段至少包括：

```java
private Long id;
private String orderNo;
private Long productId;
private String productName;
private String productCode;
private Long routeId;
private String routeName;
private String routeCode;
private Integer quantity;
private Integer status;
private LocalDateTime planStartDate;
private LocalDateTime planEndDate;
private LocalDateTime createdAt;
private LocalDateTime updatedAt;
```

- [ ] **步骤 2：在 `OrderMapper` 中新增联表查询方法**

新增按条件分页查询订单展示数据和按 id 查询订单展示详情的方法，联表 `product` 与 `route` 返回产品、路线名称与编码。

- [ ] **步骤 3：调整 `OrderService` 返回类型**

将订单列表和订单详情方法从实体返回改为 `ProductionOrderVO`：

```java
IPage<ProductionOrderVO> getOrderList(int page, int pageSize, String keyword, Integer status);
ProductionOrderVO getOrderById(Long id);
```

- [ ] **步骤 4：在 `OrderServiceImpl` 中实现展示查询和基础校验**

补充以下校验：

- `productId` 必须存在
- `routeId` 必须存在
- `quantity` 必须大于 0
- `planEndDate` 不能早于 `planStartDate`
- 只有 `未开始` 状态允许编辑和删除
- 只有 `未开始` 状态允许开工
- 只有 `进行中` 状态允许完工或取消

- [ ] **步骤 5：同步更新 `OrderController` 返回类型**

将订单列表和详情接口改为返回 `ProductionOrderVO` 或其分页结果，同时保留现有接口路径不变。
