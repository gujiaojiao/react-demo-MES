# MES 工序管理与工艺路线管理实现计划

> **给执行型 agent 的要求：** 必须使用 `subagent-driven-development`（推荐）或 `executing-plans` 按任务逐项执行。所有步骤使用 `- [ ]` 复选框跟踪。

**目标：** 补齐 MES 的工序管理页面、工艺路线管理页面，以及后端工艺路线详情接口，使用户可以维护工序主数据，并在路线下维护工序组成与执行顺序。

**架构：** 后端继续沿用 Spring Boot + MyBatis-Plus 分层结构，在现有 `process` / `route` / `route_process` 基础上新增展示型 `RouteVO` 返回对象与工序明细查询；前端沿用当前产品管理、物料管理的列表 + 弹窗模式实现工序管理，并在工艺路线列表页内通过“维护工序”弹窗维护路线下的工序顺序。

**技术栈：** React 19、TypeScript、Ant Design、React Router、Axios、Spring Boot 3、MyBatis-Plus、H2/MySQL 初始化 SQL。

```java
package com.example.admin.dto;

import com.fasterxml.jackson.annotation.JsonFormat;
import lombok.Data;

import java.io.Serializable;
import java.time.LocalDateTime;
import java.util.List;

@Data
public class RouteVO implements Serializable {
    private Long id;
    private String name;
    private String code;
    private String description;
    private Integer status;

    @JsonFormat(pattern = "yyyy-MM-dd HH:mm:ss")
    private LocalDateTime createdAt;

    @JsonFormat(pattern = "yyyy-MM-dd HH:mm:ss")
    private LocalDateTime updatedAt;

    private List<RouteProcessVO> processes;

    @Data
    public static class RouteProcessVO implements Serializable {
        private Long processId;
        private String processName;
        private String processCode;
        private Integer sequence;
    }
}
```

- [ ] **步骤 2：调整 `RouteService` 接口**

将：

```java

```

改为：

```java

```

- [ ] **步骤 3：在 `RouteProcessMapper` 中新增联表查询方法**

```java
@Select("""
    SELECT
        rp.process_id AS processId,
        p.name AS processName,
        p.code AS processCode,
        rp.sequence AS sequence
    FROM route_process rp
    LEFT JOIN mes_process p ON rp.process_id = p.id
    WHERE rp.route_id = #{routeId}
    ORDER BY rp.sequence ASC, rp.id ASC
""")
List<RouteVO.RouteProcessVO> selectProcessDetailsByRouteId(@Param("routeId") Long routeId);
```

- [ ] **步骤 4：在 `RouteServiceImpl` 中组装 `RouteVO`**

实现要点：

```java
Route route = getRouteById(id);
RouteVO vo = new RouteVO();
BeanUtils.copyProperties(route, vo);
vo.setProcesses(routeProcessMapper.selectProcessDetailsByRouteId(id));
return vo;
```

- [ ] **步骤 5：补创建/更新路线时的基础校验**

对 `routeDTO.getProcesses()` 做以下校验：

- `processId` 必须存在
- `sequence` 必须大于 0
- 同一路线内不能重复引用同一工序

可以通过：

```java
Set<Long> processIds = new HashSet<>();
for (...) {
    if (!processIds.add(item.getProcessId())) {
        throw new RuntimeException("同一路线中不能重复添加工序");
    }
}
```

并配合 `processMapper.selectById(item.getProcessId())` 校验工序存在。

- [ ] **步骤 6：同步更新 `RouteController` 返回类型**

将：

```java
public Result<Route> getRouteWithProcesses(...)
```

改为：

```java
public Result<RouteVO> getRouteWithProcesses(...)
```
