# MES 物料管理与 BOM 维护实现计划

> **给执行型 agent 的要求：** 必须使用 `subagent-driven-development`（推荐）或 `executing-plans` 按任务逐项执行。所有步骤使用 `- [ ]` 复选框跟踪。

**目标：** 补齐 MES 的物料管理页面、产品下钻式 BOM 维护页面，并完成后端 BOM 展示型接口补强与前后端联调。

**架构：** 后端继续沿用 Spring Boot + MyBatis-Plus 的分层结构，在现有 `material` / `bom` CRUD 基础上增加 BOM 展示型返回对象与校验；前端沿用当前产品管理页面的列表 + 弹窗模式实现物料管理，并新增“产品上下文内”的 BOM 详情页，通过路由参数绑定到具体产品。

**技术栈：** React 19、TypeScript、Ant Design、React Router、Axios、Spring Boot 3、MyBatis-Plus、H2/MySQL 初始化 SQL。

- [ ] **步骤 3：在 `BomMapper` 中新增联表查询方法**

```java
package com.example.admin.mapper;

import com.baomidou.mybatisplus.core.mapper.BaseMapper;
import com.example.admin.dto.BomVO;
import com.example.admin.entity.Bom;
import org.apache.ibatis.annotations.Mapper;
import org.apache.ibatis.annotations.Param;
import org.apache.ibatis.annotations.Select;

import java.util.List;

@Mapper
public interface BomMapper extends BaseMapper<Bom> {

    @Select("""
        SELECT
            b.id,
            b.product_id AS productId,
            b.material_id AS materialId,
            m.name AS materialName,
            m.code AS materialCode,
            m.type AS materialType,
            m.unit AS unit,
            b.quantity,
            b.created_at AS createdAt
        FROM bom b
        LEFT JOIN material m ON b.material_id = m.id
        WHERE b.product_id = #{productId}
        ORDER BY b.id ASC
    """)
    List<BomVO> selectBomListByProductId(@Param("productId") Long productId);
}
```

- [ ] **步骤 4：在 `BomServiceImpl` 中补产品、物料、数量校验并改用 `BomVO`**

```java
}
```
